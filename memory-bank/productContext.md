# Product Context

## Why this project exists
Job hunting is fragmented: users sift through many listings, rewrite resumes, and
guess at fit. Seeker AI aims to be a single, intelligent workspace that reduces that
friction using large language models.

## Problems it solves
- **Discovery:** surface relevant roles instead of endless browsing.
- **Fit:** match a candidate's profile/skills to job requirements.
- **Action:** draft tailored summaries, cover letters, and application notes with AI.

## How it should work (target UX)
1. User signs up / signs in (email or Google).
2. User maintains a profile (skills, experience, preferences).
3. User asks the AI assistant to find, explain, or match jobs.
4. AI returns structured, actionable results the user can save or export.

## Experience goals
- Fast, uncluttered, accessible UI (Tailwind + shadcn, semantic HTML, ARIA).
- Streaming/async interactions with clear loading and error states.
- Trustworthy AI: transparent about limits, never fabricates data.

## Audience
Job seekers (early-career to mid-level) who want an AI copilot for the search.
